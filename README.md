Smart Banking Loan & EMI Management System

A Python-based educational application designed to demonstrate loan EMI calculations, loan comparisons and repayment record management.

Features

- EMI Calculator
- Loan Comparison
- Monthly Repayment Schedule
- Total Interest and Repayment Calculation
- Saved Calculation Records
- CSV Export

Technologies Used

- Python
- Streamlit
- SQLite
- Pandas

How to Run

Install the required libraries:

python -m pip install streamlit pandas

Run the application:

python -m streamlit run smart_banking_loan_manager.py

Project Objective

To demonstrate how Python programming and database management can be applied to basic banking and financial calculations.

Disclaimer

This is an educational demonstration project. It is not an official banking application, loan approval system or creditworthiness assessment tool.
